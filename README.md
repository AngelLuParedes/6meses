# Aniversario 6 meses 💗

## Uso
```bash
npm install
npm run dev          # desarrollo (añade -- --host para probar en el celular)
npm run deploy       # publica en GitHub Pages (rama gh-pages)
```

## Personalizar
Todo se edita en `src/config.js`: fecha, nombres, carta, fotos, razones y playlist.
Coloca tus fotos en `src/assets/images/` (foto1.jpg ... foto5.jpg).
